Design motion that feels alive.

Create animated interfaces with a clean syntax, layered timing, reusable easing curves, and a small footprint that scales from prototypes to production UI. 

import { animate, stagger } from 'animejs';

animate('.card', {
  y: [24, 0],
  opacity: [0, 1],
  delay: stagger(80),
  duration: 900,
  ease: 'outExpo'
});
